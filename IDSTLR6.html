Лабораторна робота №6
Від тексту до графіки: логіка та структура

Наскрізний кейс «Цифрові звички» — скріншоти, векторна графіка та діаграми для портфоліо

Мета роботи

Опанувати інструменти візуалізації: скріншоти з прокруткою, векторну графіку в Google Drawings та професійні діаграми в Draw.io — вручну і з допомогою ШІ.

Обладнання та ПЗ

Комп'ютер з доступом до інтернету; браузер Google Chrome; корпоративний обліковий запис Google; результати Лабораторних робіт №3 і №5.

Наскрізний кейс: Ви зібрали дані (Робота 3), знайшли наукові джерела (Робота 4) та проаналізували їх за допомогою ШІ (Робота 5). Тепер — фінальний крок перед портфоліо: перетворити всі ваші результати на візуальні матеріали. Сьогодні ви навчитеся документувати власну роботу, створювати концептуальні схеми та будувати алгоритми — вручну і за допомогою коду Mermaid.

⚑ Перед початком — створіть документ звіту

Підготуйте звіт і відкрийте матеріали попередніх робіт — вони знадобляться в Етапах 1 і 3.

  1. На Google Диску перейдіть у папку Інформаційно-цифрові_системи → Лабораторні.
  2. Натисніть + Створити → Google Документи. Назвіть документ: Звіт 6 — Прізвище.
  3. Оформіть шапку: Студент(ка) 1 курсу / Прізвище Ім'я / Спеціальність 000 Назва / Лабораторна робота 6.
  4. У окремих вкладках відкрийте: вашу Google Форму з Роботи №2 (режим перегляду) та таблицю з діаграмами з Роботи №3 — вони знадобляться в Етапі 1.
  5. Залиште документ звіту відкритим — після кожного етапу вставляйте скріншот.
1

Фіксація цифрових артефактів (Awesome Screenshot)

Три типи скріншотів — документування власного дослідження для портфоліо

Що потрібно зробити

  • Встановити розширення Awesome Screenshot у браузер
  • Зробити три різні типи скріншотів із матеріалів своїх попередніх робіт
  • Завантажити скріншоти в папку на Google Диску та надати доступ за посиланням
Навіщо це потрібно: Стандартний PrtScn фіксує лише видиму частину екрана. Для портфоліо потрібні повні скріншоти сторінок — наприклад, вашої довгої анкети з Роботи №2 або таблиці з Роботи №3 з усіма діаграмами.

Покроковий алгоритм

1.1 — Встановлення розширення
  1. У браузері Chrome відкрийте Chrome Web Store (chrome.google.com/webstore) та знайдіть «Awesome Screenshot & Screen Recorder».
  2. Натисніть Додати до Chrome → Додати розширення. Іконка розширення з'явиться поруч з адресним рядком.
1.2 — Три типи скріншотів
  1. Full Page (Вся сторінка): Відкрийте вашу Google Форму з Роботи №2 у режимі перегляду. Натисніть іконку Awesome Screenshot → Capture Full Page. Завантажте результат.
  2. Visible Part (Видима частина): Перейдіть у ваш поточний звіт (документ Google Docs). Натисніть іконку → Capture Visible Part. Завантажте результат.
  3. Selected Area (Обрана область): Відкрийте таблицю з Роботи №3 із вашими діаграмами. Натисніть іконку → Capture Selected Area. Виділіть мишею лише одну найцікавішу діаграму. Завантажте результат.
1.3 — Завантаження на Диск і налаштування доступу
  1. На Google Диску у папці Інформаційно-цифрові_системи створіть підпапку Скріншоти_ЛР6.
  2. Завантажте всі три скріншоти в цю папку: + Створити → Завантажити файли.
  3. Виділіть усі три файли → правий клік → Надати доступ → змініть на «Усі, у кого є посилання — Переглядач» → скопіюйте посилання на кожен файл.
  4. Вставте всі три посилання у документ звіту, підписавши тип кожного.

Векторна графіка (Google Drawings)

Діаграма Венна «Моя ідеальна професія» — прозорість, шари, групування

Що потрібно зробити

  • Створити діаграму Венна з трьох кіл із прозорою заливкою
  • Підписати кола та центр відповідно до вашої спеціальності
  • Згрупувати всі елементи та надати доступ за посиланням
Растр vs Вектор: Звичайні скріншоти — це растрові зображення (сітка пікселів). Google Drawings створює векторну графіку — її можна масштабувати без втрати якості. Саме такий формат потрібен для презентацій і сайтів.

Покроковий алгоритм

2.1 — Створення та налаштування кіл
  1. На Google Диску натисніть + Створити → Інше → Google Малюнки. Назвіть файл: Діаграма Венна — Прізвище.
  2. На панелі інструментів натисніть Фігури → Еліпс. Утримуючи Shift, намалюйте коло. Намалюйте три кола, які частково перетинаються.
  3. Для кожного кола налаштуйте прозору заливку: виділіть коло → Колір заливки → Спеціальний → оберіть колір → повзунком встановіть прозорість 50–60%.
  4. Дайте кожному колу свій колір: наприклад, зелений / синій / жовтий.
2.2 — Текстові підписи та групування
  1. Додайте текстові написи у кожне коло: Вставити → Текстове поле.
Зміст кіл
Коло 1: «Що я вмію» + Коло 2: «Що мені подобається» + Коло 3: «Що потрібно ринку» → Центр: ваша спеціальність
  1. Виділіть усі елементи (Ctrl+A) → меню Упорядкувати → Згрупувати — всі об'єкти стануть одним цілим.
  2. Натисніть кнопку Надати доступ → «Усі, у кого є посилання — Переглядач» → скопіюйте посилання.

Професійні діаграми (Draw.io)

Алгоритм дослідження вручну + автоматична схема через Mermaid і Gemini

Що потрібно зробити

  • Вручну побудувати блок-схему ходу вашого дослідження (Роботи 1–6)
  • Попросити Gemini згенерувати Mermaid-код для складної схеми
  • Імпортувати код у Draw.io та отримати автоматично побудовану діаграму

Покроковий алгоритм

3.1 — Ручна блок-схема в Draw.io
  1. Перейдіть на app.diagrams.net → у вікні збереження оберіть Google Drive → авторизуйтесь → натисніть Create New Diagram → оберіть порожню діаграму.
  2. Назвіть файл Діаграми_ЛР6 — Прізвище та збережіть у папку Інформаційно-цифрові_системи.
  3. Побудуйте блок-схему з правильними фігурами: овал — початок/кінець, прямокутник — процес, стрілки — напрямок.
Орієнтовний ланцюжок блоків
Початок → Цифрове середовище (ЛР1) → Анкетування (ЛР2) → Аналіз даних (ЛР3) → Пошук джерел (ЛР4) → ШІ-аналіз (ЛР5) → Візуалізація (ЛР6) → Портфоліо → Кінець
  1. Розфарбуйте блоки: використайте різні кольори для різних типів (початок/кінець, процеси, результат).
  2. Збережіть файл: File → Save.
3.2 — Генерація схеми через Gemini + Mermaid
  1. Відкрийте gemini.google.com та оберіть одну тему:
Варіанти теми (оберіть один)
Ментальна карта цифрових інструментів сучасного студента Блок-схема структури ідеальної курсової роботи Алгоритм підготовки студента до сесії
  1. Вставте у Gemini промпт (підставте обрану тему):
Промпт для Gemini
Згенеруй код формату Mermaid для: [обрана вами тема]. Використовуй українську мову для назв блоків. Виведи ТІЛЬКИ код — без пояснень і без markdown-огорожі (без ```)
Якщо Gemini додав ``` на початку і в кінці — видаліть їх перед вставкою в Draw.io
  1. Скопіюйте згенерований код.
  2. Поверніться у Draw.io. Знайдіть пункт меню Extras → Edit Diagram (або + на лівій панелі → пошук «Mermaid»).
  3. У вікні, що відкрилось, вставте скопійований код та натисніть Insert / OK.
  4. Діаграма автоматично з'явиться на полотні. Розмістіть її поруч із ручною схемою з пункту 3.1.
  5. Збережіть файл. На Google Диску правий клік → Отримати посилання → «Переглядач» → скопіюйте.
Якщо Mermaid-код не імпортується: Gemini іноді генерує синтаксис із помилками. Спробуйте написати у Gemini: «Перевір і виправ цей Mermaid-код — він не імпортується в Draw.io» та вставте проблемний код.

4

Експорт та вставка у звіт

Перетворення діаграм на зображення — готові матеріали для портфоліо

Що потрібно зробити

  • Експортувати діаграму Венна з Google Drawings як PNG
  • Експортувати блок-схему з Draw.io як PNG
  • Вставити обидва зображення безпосередньо у документ звіту
Навіщо це потрібно: Посилання на файл — це зручно для перевірки, але для портфоліо або презентації потрібні готові зображення. Цей етап показує повний цикл: створили → зберегли → використали.

Покроковий алгоритм

4.1 — Експорт із Google Drawings
  1. Відкрийте файл Діаграма Венна — Прізвище у Google Drawings.
  2. Меню Файл → Завантажити → PNG — зображення збережеться на комп'ютер.
4.2 — Експорт із Draw.io
  1. У Draw.io виберіть ручну блок-схему (або всі елементи Ctrl+A).
  2. Меню File → Export As → PNG → натисніть Export → збережіть на комп'ютер.
4.3 — Вставка зображень у звіт
  1. Відкрийте документ Звіт 6 — Прізвище.
  2. Меню Вставити → Зображення → Завантажити з комп'ютера → оберіть PNG діаграми Венна. Підпишіть: «Діаграма Венна — Google Drawings».
  3. Аналогічно вставте PNG блок-схеми з Draw.io. Підпишіть: «Алгоритм дослідження — Draw.io».
